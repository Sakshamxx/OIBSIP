
# Car Price Prediction with Machine Learning

## Overview

A machine learning regression project that predicts the selling price of used cars based on features such as car brand, model, age, mileage, fuel type, transmission, and other vehicle attributes.

The project focuses on data cleaning, feature engineering, outlier handling, categorical encoding, feature selection, regression modeling, and model evaluation.

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Load and understand the dataset
2. Data cleaning and preprocessing
3. Handle missing values and duplicates
4. Feature engineering
5. Detect and remove extreme outliers
6. Exploratory Data Analysis
7. Feature selection
8. Encode categorical variables
9. Train-test split
10. Train regression models
11. Evaluate models using MAE, RMSE and R²
12. Compare models
13. Select the best-performing model
14. Analyze feature importance
15. Predict the selling price of a new car

## Models Used

- Linear Regression
- Random Forest Regressor
- Extra Trees Regressor

## Dataset

The project uses the CarDekho used-car dataset containing information about used cars and their selling prices.
