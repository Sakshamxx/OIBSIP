
# Iris Flower Classification

## Overview

A machine learning classification project that predicts the species of an iris flower using its physical measurements.

The project analyzes the Iris dataset and compares multiple classification algorithms to determine the best-performing model.

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Load the Iris dataset
2. Exploratory Data Analysis
3. Data visualization
4. Feature selection and analysis
5. Train-test split
6. Train classification models
7. Evaluate model performance
8. Compare models
9. Select the best model
10. Make final predictions

## Dataset

The Iris dataset is built directly into Scikit-learn and contains measurements of three iris species:

- Setosa
- Versicolor
- Virginica

The features used include:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Models Used

- Logistic Regression
- K-Nearest Neighbours
- Decision Tree
- Random Forest

## Evaluation

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

The confusion matrix is also visualized to understand the classification performance of the selected models.

## Objective

The main objective is to understand the complete classification workflow and identify which machine learning model performs best at distinguishing the three Iris species.
