
# Unemployment Analysis in India

## Overview

A data analysis project that explores unemployment trends across different regions of India, with a focus on changes before and during the COVID-19 period.

The project uses exploratory data analysis and visualizations to identify regional differences, temporal trends, and relationships between unemployment, employment, and labour participation.

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. Load and understand the dataset
2. Clean and prepare the data
3. Handle missing values and data types
4. Perform exploratory data analysis
5. Analyze region-wise unemployment rates
6. Analyze monthly unemployment trends
7. Visualize unemployment trends for major regions
8. Compare states with the highest average unemployment
9. Analyze correlations between unemployment, employment, and labour participation
10. Compare pre-COVID and post-COVID unemployment
11. Draw key observations from the analysis

## Dataset

The project uses the **Unemployment in India** dataset containing unemployment-related statistics across Indian regions and time periods.

Key variables include:

- Region
- Date
- Estimated Unemployment Rate
- Estimated Employed
- Estimated Labour Participation Rate

## Visualizations

The project includes:

- Time-series unemployment trend
- Regional average unemployment bar chart
- Top 10 regions by unemployment rate
- Correlation heatmap
- Pre-COVID vs post-COVID comparison

## Objective

The main objective is to understand how unemployment varied across Indian regions and over time, and to identify the changes associated with the COVID-19 period.
